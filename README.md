## ✨ Features & Highlights

- **⚡ 60 FPS Interactive Particle Canvas:** Custom-painted particle constellation with aurora vortex, touch particle interactions, and optimized squared-distance math for high-performance rendering.
- **🎴 Developer 3D ID Card:** Glassmorphic cyber ID card with QR code link to GitHub profile, avatar loader, status indicators, and responsive perspective transforms.
- **🪐 Concentric Skill Orbit:** Orbital visualization categorizing technical skills across Languages, Frameworks, Databases, and Cloud/Tools, with a responsive mobile fallback grid.
- **💻 Expandable Case Studies:** Interactive project cards featuring rotating holographic conic-gradient borders, architecture breakdowns, problem statements, and live source links.
- **⚡ Terminal-Style Bio (`cat bio.md`):** Clean command-line interface card presenting background, full-stack core competencies, and cloud security learning milestones.
- **📱 100% Fully Responsive:** Responsive breakpoints tailored across mobile phones, tablets, laptops, and ultra-wide displays.
- **🌓 Dynamic Dark / Light Themes:** Cyber Midnight dark mode and sleek light mode with smooth palette transitions.
- **🚀 Automated CI/CD:** Continuous Integration & Deployment via GitHub Actions workflow (`deploy.yml`) publishing directly to GitHub Pages on `main` branch push.

## 🚀 Getting Started Locally

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.x or higher)
- [Dart SDK](https://dart.dev/get-dart)
- Google Chrome or any modern Web Browser

### Installation

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/Ashwin-R05/Portfolio.git
   cd Portfolio
   ```

2. **Install Dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run Locally in Browser:**
   ```bash
   flutter run -d chrome
   ```

4. **Build Production Web Release:**
   ```bash
   flutter build web --release
   ```
